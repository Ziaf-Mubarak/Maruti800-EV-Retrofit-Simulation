# Maruti800-EV-Retrofit-Simulation
This project presents the retrofit design of a Maruti 800 Internal Combustion Engine vehicle into an Electric Vehicle using MATLAB, Simulink and Simscape.  
The work includes:  
• Vehicle dynamics calculations 
• Battery sizing • Motor sizing 
• Thermal modelling 
• Drive cycle generation 
• EV performance simulation 
• Cost and feasibility analysis

# Maruti800 EV Retrofit Simulation

## Overview

This project demonstrates the conversion of a Maruti 800 Internal Combustion Engine vehicle into an Electric Vehicle using MATLAB, Simulink and Simscape.

## Original Reference Model

This project is based on the MathWorks BEV Reference Application:

https://github.com/mathworks/Simscape-Battery-Electric-Vehicle-Model

## My Contributions

- Implemented 48V battery system
- Configured 12kW PMSM motor

- Analysed vehicle performance

## Setup

1. Install MATLAB
2. Install Simulink
3. Install Simscape
4. Download MathWorks BEV Reference Application
5. Place BEV_MASTER.m inside the project folder
6. Run:

```matlab
BEV_MASTER
```
