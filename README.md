# Maruti800-EV-Retrofit-Simulation
This project presents the retrofit design of a Maruti 800 Internal Combustion Engine vehicle into an Electric Vehicle using MATLAB, Simulink and Simscape.  
The work includes:  
• Vehicle dynamics calculations 
• Battery sizing • Motor sizing 
• Thermal modelling 
• Drive cycle generation 
• EV performance simulation 
• Cost and feasibility analysis
